# Windows session control: delivered scope and remaining work

The original Windows transcript mirror remains read-only. An arbitrary already-running native terminal is not a broker-owned PTY and cannot be controlled by the existing WSL terminal broker. No live process was stopped or its transcript rewritten.

Official Claude Code Remote Control supports enabling /remote-control within an existing interactive session without closing it, and controlling that same conversation through claude.ai/code or the Claude app. Source verified: https://code.claude.com/docs/en/remote-control . This requires the owner's eligible Claude login and native CLI one-time Remote Control confirmation. Agent House does not impersonate Claude's control protocol or enable remote access silently.

Delivered: Windows session detail explains the distinction and lets an operator save/remove the session's official Claude control link and open it in a separate tab. The central gateway stores the mapping per qualified host/workspace/session, in an atomic mode-0600 file, after checking the session exists in that remote workspace. Windows host software does not need an update for this central mapping. Links require HTTPS, the exact claude.ai hostname, no credentials or custom port, and /code path. No model prompt, stop, takeover or terminal input is sent while saving a link. This is a user-supplied shortcut, not an independently verified native remote-session identity. Local host implementation supports the same metadata API for future deployment.

Verification: 227 full backend tests and 105 UI tests passed; build passed. An additional central-gateway mapping regression test passed in the 8-test Windows suite (persist/reload, scope isolation, no forwarded mutation). Existing live native jobs preserved. Real Remote Control activation and message exchange are pending the owner enabling it inside the chosen Windows session and pasting its actual link.

Remaining: native Windows broker launch/control within Agent House, a real end-to-end controlled session test, and the separate WSL project-trust issue for new panel-created execution. Do not present the external Claude control link as Agent House inline terminal ownership or as completed arbitrary terminal takeover. Closed-session cross-OS transcript migration was not implemented: it needs verified resume semantics and conflict handling.
