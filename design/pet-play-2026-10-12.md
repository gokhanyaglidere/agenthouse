# Idle pet interaction

Idle agents can approach a nearby idle native pet from an accessible side tile. The pet waits while the agent approaches. Only one agent is paired with each animal. At arrival the agent faces and strokes it for a six-second cosmetic visit, followed by a little toy-ball animation; the pet faces back, displays its existing heart bubble and subtly bobs. This is decorative play, not a simulated fetch/physics game. Afterwards the animal follows for four seconds, with a fifteen-second cooldown.

Busy agents, hidden/despawning characters and private-office occupants are excluded. Machine use, dining and watering take priority. Real work, expiry, deleted pets/agents and invalid identity bindings release the interaction. Removal never changes a working agent's state. CEO confinement and occupied approach tiles are respected.

Layout revision 121 adds the bundled native Gitcat companion to existing layouts with pets enabled, preserving disabled-pet layouts and later user removals.
