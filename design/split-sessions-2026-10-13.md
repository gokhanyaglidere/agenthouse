# Side-by-side sessions

Sessions → Yan yana oturumlar offers 2, 3 or 4 independent panes. Registered projects can be mixed. Each pane uses a small same-origin embedded document with its own immutable workspace scope, transcript cursor, terminal connection and scoped draft storage. The office renderer is not mounted in embedded documents. Selectors exclude duplicate session choices; changing one selection does not remount other panes. Layout and selections survive refresh and switching back to single-session view in the same browser tab. Unregistered projects require registration first.

Selecting a session reads history only. Explicit “Canlı terminale bağlan” uses the existing terminal broker and permission checks; external CLI jobs are never silently taken over. The existing account limit of 3 panel jobs and one writable worker per project directory remains enforced on the server. Four visible panes do not grant four active workers. Closing a pane disconnects its UI, not the Claude process. Embedded terminals disable modal focus trapping, so users can move between panes; no server/auth policy was weakened.

Responsive layout: 3 columns on wide desktop, 2 columns at intermediate widths, stacked panes on narrow screens; 4 panes use a 2×2 grid. History scrolls independently. Empty/history/error states and manual transcript refresh are present. Transcript history is not a live stream; use the live terminal for continuous output.
